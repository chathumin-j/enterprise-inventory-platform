A production-style Spring Boot backend for managing products, warehouses, and stock movements. Built with Java 21 and Spring Boot 4, it features JWT authentication with role-based access control, Redis-backed caching with explicit cache hit/miss/eviction logging, Flyway-versioned MariaDB schema migrations, and structured JSON logging shipped to an ELK stack for centralized observability. Fully containerized with Docker Compose for one-command local setup.
